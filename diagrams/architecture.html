Authentication Flow

Three-tier authentication system: Clerk handles user identity, Inngest synchronizes user data to the database, and custom middleware authorizes admin and seller actions.

User Registration & Login (Clerk + Inngest Sync)

sequenceDiagram actor User participant Browser participant Clerk as Clerk Auth participant Inngest as Inngest participant API as Next.js API participant DB as Neon Postgres User->>Browser: Sign Up / Sign In Browser->>Clerk: Clerk UI Component Clerk-->>Browser: JWT Token + Session Note over Clerk,Inngest: Webhook on user.created Clerk->>Inngest: clerk/user.created event Inngest->>API: POST /api/inngest API->>DB: prisma.user.create({id, email, name, image}) DB-->>API: User created API-->>Inngest: Success Note over Clerk,Inngest: Webhook on user.updated Clerk->>Inngest: clerk/user.updated event Inngest->>API: POST /api/inngest API->>DB: prisma.user.update(...) DB-->>API: User updated Note over Clerk,Inngest: Webhook on user.deleted Clerk->>Inngest: clerk/user.deleted event Inngest->>API: POST /api/inngest API->>DB: prisma.user.delete(...) DB-->>API: User deleted

API Request Authentication

sequenceDiagram actor User participant Browser participant Clerk as Clerk SDK participant API as Next.js API Route participant MW as Middleware participant DB as Neon Postgres User->>Browser: Perform action (e.g., place order) Browser->>Clerk: getToken() Clerk-->>Browser: JWT Bearer Token Browser->>API: Request + Authorization header API->>API: getAuth(request) → extract userId alt Public API (products, about) API->>DB: Query without auth check DB-->>API: Data end alt Authenticated API (cart, orders, rating) API->>API: Check userId exists alt userId missing API-->>Browser: 401 Not Authorized else userId valid API->>DB: Query with userId filter DB-->>API: Data end end alt Admin API (/api/admin/*) API->>MW: authAdmin(userId) MW->>Clerk: clerkClient.users.getUser(userId) Clerk-->>MW: User email MW->>MW: Compare email with ADMIN_EMAIL env alt Email matches MW-->>API: true (authorized) API->>DB: Admin operation else Email mismatch MW-->>API: false API-->>Browser: 403 Forbidden end end alt Seller API (/api/store/*) API->>MW: authSeller(userId) MW->>DB: prisma.store.findUnique({userId}) alt Store exists and status == approved MW-->>API: storeId API->>DB: Seller operation else No store or not approved MW-->>API: null API-->>Browser: 403 Forbidden end end

Technology Decision Sheet

Rationale behind every major technology choice in the GoCart stack, including alternatives considered and why each decision was made.

Layer Technology Version Rationale Alternatives Considered
Framework Next.js (App Router) 16.1.6 Full-stack React framework with SSR, API routes, file-based routing, and Edge/Serverless support. App Router enables React Server Components and streaming. Remix, Nuxt.js, plain Express + React
UI Library React 19.2.3 Latest React with concurrent features, Server Components support, and improved performance. Largest ecosystem of component libraries. Vue 3, Svelte, Solid.js
State Mgmt Redux Toolkit + React-Redux 2.11.2 Predictable centralized state for cart, products, addresses, and ratings. Built-in async thunk support via createAsyncThunk. Four slices keep concerns separated. Zustand, Jotai, React Context
Auth Clerk 6.38.2 Fully managed auth with pre-built UI components, JWT sessions, webhook events, and a Clerk+ membership plan system. Eliminates need to build login/register flows manually. NextAuth.js, Auth0, Supabase Auth, Firebase Auth
Database Neon Serverless Postgres — Fully managed PostgreSQL with serverless scaling, branching for dev environments, and instant cold-start. HTTP driver works natively in Edge/Serverless without persistent connections. Supabase Postgres, PlanetScale, AWS RDS, Railway Postgres
ORM Prisma + @prisma/adapter-neon 5.22.0 Type-safe database access with auto-generated client, migrations, and relation handling. The Neon adapter enables HTTP-based queries for serverless compatibility (no connection pooling needed). Drizzle ORM, Kysely, raw SQL via @neondatabase/serverless
Payments Stripe 20.4.1 Industry-standard payment processing with Checkout Sessions for secure PCI-compliant payment collection. Webhook-driven architecture ensures reliable order confirmation. Supports multi-store marketplace payout models. Razorpay, PayPal, LemonSqueezy
AI OpenAI 6.27.0 Powers AI-generated review summaries. Uses GPT to analyze up to 80 customer reviews and produce a concise insight paragraph. Configurable via OPENAI_BASE_URL to swap providers. Anthropic Claude, Google Gemini, Hugging Face, local LLMs
Background Jobs Inngest 3.52.3 Event-driven serverless job runner. Handles: (1) Clerk user sync (create/update/delete), (2) Coupon auto-deletion via step.sleepUntil(). Durable execution guarantees even across deploy cycles. Trigger.dev, QStash, BullMQ + Redis, AWS SQS
Image CDN ImageKit 4.1.4 Server-side image upload with automatic optimization, resizing, and global CDN delivery. Used for store logos and product images. Simple SDK with URL-based transformations. Cloudinary, AWS S3 + CloudFront, Uploadthing
Styling Tailwind CSS 4.x Utility-first CSS framework. v4 uses CSS-native engine (no PostCSS plugin needed for JIT). Rapid UI prototyping with consistent design tokens. Used with @tailwindcss/postcss. Vanilla CSS, Styled Components, CSS Modules, UnoCSS
Typography Outfit (Google Fonts) — Modern geometric sans-serif with multiple weights (400, 500, 600). Loaded via next/font/google for automatic optimization and zero layout shift. Inter, Poppins, DM Sans
HTTP Client Axios 1.13.6 Promise-based HTTP client with interceptors, automatic JSON transforms, and request/response error handling. Used in Redux async thunks for API calls. Native fetch, ky, got
Charts Recharts 3.7.0 React-native charting library built on D3. Used in admin dashboard for orders area chart visualization. Declarative API with responsive containers. Chart.js, Nivo, Tremor, Victory
Icons Lucide React 0.564.0 Lightweight, tree-shakable icon library with 1000+ consistent icons. Fork of Feather Icons with active community maintenance. React Icons, Heroicons, Phosphor Icons
Notifications React Hot Toast 2.6.0 Lightweight toast notification library with promise-based API, customizable styling, and accessible defaults. Minimal bundle impact. Sonner, React Toastify, Notistack
Date Utils date-fns 4.1.0 Modular date utility library. Tree-shakable functions — only import what you use. Used for formatting order dates and coupon expiry display. Day.js, Luxon, Temporal API
